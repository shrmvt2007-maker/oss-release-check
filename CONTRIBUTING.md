# Contributing

Thanks for considering a contribution.

## Before opening a pull request

1. Describe the problem the change solves.
2. Keep changes focused and explain any behavior change in the README.
3. Run the command against a few local repositories and inspect the output manually.
4. Do not include private repository contents, credentials, or personal data in examples.

Open an issue first for large changes so maintainers can discuss the approach. By submitting a contribution, you agree that it is offered under the repository's MIT license.
